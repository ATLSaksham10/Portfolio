# Image guidelines

- Export photos as **WebP** when possible.
- Hero / header images: max **2000px** wide.
- Card / grid images: max **1200px** wide.
- Keep files under **~300 KB** when you can.
- Name files by slug, e.g. `project-one-hero.webp`, `about-lab-01.webp`.
- If a file is missing, pages fall back to `placeholder.svg`.
- Always set `alt` text in HTML (or the data field that feeds it).
