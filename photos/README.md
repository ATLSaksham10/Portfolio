# Photos

All site pictures live here as `.jpg`, named exactly as the code expects. To swap one, save the new photo over the old file with the same name. Keep each file under ~400 KB (about 1400 px on the long side; hero images up to 2000 px wide).

| File | Where it appears |
|---|---|
| `portrait.jpg` | Home and About portrait (4:5) |
| `about-1.jpg` to `about-6.jpg` | About page photo gallery (captions are in `about.html`) |
| `social-preview.jpg` | Link preview image for every page (1200×630) |
| `featured-video.jpg`, `featured-article.jpg` | Featured page cards |
| `cat-hero.jpg`, `cat-cad.jpg`, `cat-1.jpg` to `cat-4.jpg` | Caterpillar project |
| `frc-hero.jpg`, `frc-cad.jpg`, `frc-bumper.jpg`, `frc-1.jpg` to `frc-5.jpg` | FRC robot project |
| `sunroom-hero.jpg`, `sunroom-model.jpg`, `sunroom-drawing.jpg`, `sunroom-1.jpg` | Sunroom project |
| `drone-hero.jpg`, `drone-claw.jpg`, `drone-fea.jpg`, `drone-1.jpg` to `drone-3.jpg` | TSA drone project |

Each project's `*-hero.jpg` is both the page banner and the card photo on the Projects page. Captions for project photos are in `projects/*.html`.

Full-size originals are kept outside the repo, in `~/Downloads/portfolio-photo-originals/`.
